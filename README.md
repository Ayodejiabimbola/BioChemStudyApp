\# BioChemStudyApp



A console application built in C# to combine Biochemistry study tools with software engineering practice.



\## Features



\- \*\*Study Session Logger\*\* — Track study time by subject with automatic date logging

\- \*\*View Study Log\*\* — Review all past study sessions

\- \*\*Molecular Weight Calculator\*\* — Calculate molecular weights from chemical formulas (H2O, C6H12O6, NaCl, etc.)

\- \*\*Biochemistry Quiz\*\* — Test your knowledge with a 5-question quiz and high score tracking



\## Tech Stack



\- C# Console Application

\- .NET

\- File I/O for data persistence



\## How to Run



```bash

dotnet run

```
